# Tierra & Tueste - Cafetería

## Propósito del sitio
Este sitio web fue creado para la cafetería **Tierra & Tueste**. Su objetivo es mostrar 
nuestros productos artesanales, permitir que los clientes conozcan nuestra ubicación, 
puedan contactarnos fácilmente y leer las reseñas de otras personas que ya nos visitaron.

## Páginas del sitio
- **Inicio**: Presentación de la cafetería con un video y botón para ir a productos.
- **Productos**: Catálogo de cafés con precios y descripciones.
- **Reseñas**: Opiniones de clientes (se encuentra dentro de la página de productos).
- **Contacto**: Formulario para enviar mensajes y mapa con la ubicación.
- **Carrito**: Página para ver los productos elegidos (en desarrollo).

## Tecnologías utilizadas
- **HTML5** para la estructura del sitio.
- **CSS3** para los estilos, con Flexbox, Grid y Media Queries.
- **Google Fonts** para las tipografías (Playfair Display y Plus Jakarta Sans).
